# Changelog

All notable changes to Wapliss WhatsApp for Grok. Created and maintained by netdigitaltech.

## 1.0.0 - 2026-11-10

- First release for Grok Build: `.grok-plugin/plugin.json`, `.mcp.json` with the hosted
  Wapliss MCP server (`https://wapliss.com/mcp/v1`, Streamable HTTP, OAuth handled by Grok),
  the `wapliss-whatsapp` skill and a 512 × 512 logo.
- Same 16 tools as the other Wapliss plugins (Claude, ChatGPT, Gemini, DeepSeek, GitHub Copilot).
- `scripts/validate.py`: manifest, MCP config and skill checks (`--live` checks the endpoint).
